# Local AI Manager — Windows x64

В проект добавлена автоматическая сборка Windows x64 через GitHub Actions.

## Получение готового EXE и установщика

1. Загрузите содержимое этой папки в GitHub-репозиторий.
2. Откройте вкладку **Actions** и выберите **Build Local AI Manager for Windows**.
3. Нажмите **Run workflow** и дождитесь завершения сборки.
4. Внизу страницы запуска скачайте артефакт **Local-AI-Manager-Windows-x64**.
5. Внутри будут:
   - `LocalAIManager-Windows-x64.zip` — portable-версия, распаковать целиком и запустить `LocalAIManager.exe`;
   - `LocalAIManager_Setup_v*.exe` — установщик, создающий ярлыки в меню «Пуск» и на рабочем столе.

Для portable-версии можно запустить `create_desktop_shortcut.ps1` из папки приложения, чтобы создать ярлык на рабочем столе с фирменной иконкой.

## Важно

Windows EXE должен собираться на Windows: PyInstaller не выполняет надёжную кросс-компиляцию Windows-приложений из Linux. Поэтому в текущей среде подготовлены исходники и автоматическая Windows-сборка, но готовый EXE здесь не выдаётся за собранный и проверенный.
