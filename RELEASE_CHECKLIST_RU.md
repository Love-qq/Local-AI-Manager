```powershell

python -m pytest -q
```

## Сборка и релиз

1. Запустить GitHub Actions workflow **Build Local AI Manager for Windows**.
2. Убедиться, что тесты и сборка завершились успешно.
3. Скачать артефакты portable ZIP и Setup EXE.
4. Проверить их на чистой Windows 10/11 x64 без Python.
5. Проверить цифровые подписи/предупреждения SmartScreen. Пока проект не подписан сертификатом, Windows может показывать предупреждение неизвестного издателя.
6. Создать GitHub Release с номером версии, кратким списком изменений, известными ограничениями и SHA-256 файлов.
7. Не называть релиз стабильным, пока не пройдены ручные проверки.
